## 2. 交付级口径限制（说之前必须想清楚）

### 2.1 干净的「真实带货直播」样本 = 0 场

全库 18 个会话的音源画像核查结论：

| 会话 | 内容实质 | 可否用于统计 |
|---|---|---|
| `b217299a` | 古装剧对白 | ⚠️ 仅限「电视类连续语音」，**不可作带货样本** |
| `f941151f` | 文化讲解/纪录片 | ⚠️ 同上 |
| `d61e4b32` | **未定**（非 TTS、非影视剧） | ❌ 不得用于任何统计 |
| `5970a6d6` | 带货 TTS | ❌ 不可用于「真实直播」统计 |
| `190ba540` / `ae85dc7c` | 带货 TTS（第①级测试音） | ❌ 同上 |
| `2920b432` | **混合会话**（广告口播 + 无源间隙 + TTS） | ⛔ 只有 0~124.8s 干净区间可用 |

**因此：严禁说「已用真实带货直播验证」。** 现有实测素材是 TTS 测试音、公开转播广告口播、影视剧对白——**都不是带货直播**。

### 2.2 「流标签」不等于「内容性质」

播放源标签 `cctv13hd.m3u8` 的时隙实播为**降糖保健品广告口播**，**不是新闻**。引用流地址时不能把标签当内容依据。

### 2.3 会话引用纪律（全组生效）

引用任何会话的**统计**必须同时标注**所属时间区间**；**只写 sessionId 的引用一律视为无效引用**（`2920b432` 的 49.8s 是音源切换间隙，不是静默极值；干净窗口内最长 VAD 空隙仅 0.4s）。

## 3. 产品行为限制

1. **报告部分统计字段未统计**：ASR 连接/断线/缺口数、LLM 请求/失败数在 JSON 中为 `null`、HTML 标注「未统计」——实时事件未持久化，无法事后回算。**不要拿 `analysisRuns` 数量冒充请求数。**
   - `tests/report.test.ts` 通过只证明报告结构与口径逻辑（统计与库一致、HTML 转义、导出无密钥、脱敏），**不代表真实导出的报告里这些字段有值**。
2. **精确分析倒计时未实现**：UI 只显示最近分析状态。
3. **话术步骤阶段靠关键词触发**：漏说关键词的阶段不会出现在覆盖统计里。
4. **短会话尾部窗口可能不分析**：会话在调度边界前结束时，最后一个窗口可能未触发，最终字幕仍保存。
5. **跨片段同一语义问题不合并**：换证据仍属同一语义问题的聚合策略未实现。
6. **会话自动结束**：现已有「按排期窗口结束」路径，但无人值守的**到点自动开始未接通**；一旦开录而未结束，会持续采集、持续送 ASR、**持续计费**并造成跨场次污染（实测有会话挂 622 分钟）。
7. **未配置 LLM 时会重复弹 `LLM_NOT_CONFIGURED`**：按 60 秒间隔一小时约 60 条，会淹没真实提示。看到该提示表示未配置密钥，**规则引擎仍在正常工作**，不是产品故障。
8. **规则命中只是风险候选**：词法规则不能核实商品事实、不能认定违法；LLM 只输出风险提示与人工核查建议。
9. **`paceThreshold` / `silenceThresholdMs` 有 schema 无 UI 入口**。
10. **LLM 修复重试计入预算**：一次分析最多计 2 次请求；预算单位是**请求次数**，不是钱或 token。
11. **安装包未签名**（离线环境），双击会触发 SmartScreen 提示；**应用图标缺失**（使用 Electron 默认图标）。
12. **preload 中 8 个方法用字符串字面量而非 `IpcChannels` 常量**（当前值一致，未来改常量不会报错）；`capture.listDevices` 常量已定义但无 handler。
13. **DNS 瞬失败**：出现过 `getaddrinfo EAI_AGAIN asr.cloud.tencent.com`；持续断网时无法得到云端字幕。
14. **`ReportFormat` 枚举名曾为 `markdown` 但实际产出 HTML**：已改为 `["html","json"]` 并保留 `markdown` 作输入别名归一化。
15. **采集设备健康三级判据（L1 `ended` / L2 `muted` / L3 设备消失 / L4 仅电平为 0）**：设计已出，其中 L4 的旧判据（回调停更）**已废弃**并改读 `AudioContext.state`。

## 4. 隐私边界（不得简化为「数据不出本机」）

### 4.1 两句话必须一起说

- **本地**：会话、转写、问题、设置保存在本机 SQLite（`%APPDATA%/ai-live-monitor/live-monitor.db`）；**音频不落盘**（不保存原始音频文件）。
- **出网**：ASR **音频**（16kHz/16bit/单声道，200ms 一包）**上传腾讯云**；LLM **窗口内转写文本**上传所配置的 OpenAI 兼容服务。

> **因此「数据不出本机」是错误表述。** 正确说法是「应用与数据存储在本机；音频送 ASR、转写送 LLM」。

### 4.2 密钥

- 只从**进程环境变量**读取：`DSH_SECRET_TENCENT_ASR_SECRET_ID` / `DSH_SECRET_TENCENT_ASR_SECRET_KEY` / `DSH_SECRET_LLM_API_KEY`。
- **不入库、不进日志、不进错误提示、不进导出报告**；界面不提供密钥输入框（产物实测 `PASSWORD_INPUTS=0`）。
- 公开配置（APPID、base_url、model）可存设置页；`settings.get` 不回显历史敏感字段。
- 错误文本经 `redactSecrets()` 脱敏（`secretid`/`secret_key`/`api_key`/`authorization`/`token`/`signature`/`AKID*`/`sk-*`）。
- **不得**通过注册表、启动脚本或数据库注入密钥绕过环境变量。
- ⚠️ **历史遗留的明文密钥记录未被清理**（运行链路已不读取）。

### 4.3 数据处理范围

- 单场预算默认 10 次 LLM 请求；超限后停止 LLM 分析（本地规则继续生效）。
- 卸载**不删除**数据库；彻底清除需手动删除 `%APPDATA%/ai-live-monitor/`。
- 演示/验收中若使用了手势旁路 `AILIVE_ACCEPTANCE_NO_GESTURE_CAPTURE=1`，**必须标注**；该旁路默认关闭，**不得出现在交付配置中**。

## 5. 环境依赖与硬约束（复现必读）

1. **本机 PowerShell 直接跑 npm 会被脚本执行策略拦截** → 用 `cmd /c "npm ..."`。
2. **启动 Electron 前必须 `$env:ELECTRON_RUN_AS_NODE = $null`**（本机默认为 `1`，会让 `require('electron')` 只返回 exe 路径）。
3. **重装依赖后必须 `npm run abi:electron`** 重建 better-sqlite3 ABI（Electron 33 要 modules 130，本机 Node 24 要 137）。
4. 跑测试用 `npm test`（electron-node、单次 run、内部清空 `DSH_SECRET_*`），**不要在测试前后切 ABI**。
5. 交付态系统声音采集**必须真实用户点击**；自动化验收若用了手势旁路必须标注。
6. macOS 若要做系统声采集，需先装 BlackHole 等虚拟声卡。
