## 关键结论（截至 2026-10-14 22:xx）

- 鉴权：HMAC-SHA1 旧版签名（非 TC3）与腾讯云文档一致，真实密钥下握手成功，0 次鉴权失败。
- 音频：TTS 生成 20 段直播口语中文语音，拼成 972 个 200ms 包，按 1:1 实时率发送。
- 稳态结果：非空，内容含网络用语（"家人们谁懂啊"）、品牌/成分词（"烟酰胺""二裂酵母""依克多因"）、数字（"300多""5%""7天"），识别质量可用。
- 时间戳：单连接内 `index` 与 `start_time/end_time` 均从 0 起、单调递增；重连后重新从 0 计数（协议行为，需由上层重新锚定）。
- 端到端延迟：见 `websocket-probe-3min.json` 的 `e2eMs` / `firstTokenLatencyMs`。

## 测量方法

1. **端到端延迟（e2eMs）**：`final 到达时刻 − (该连接第一包音频送出的会话时钟 + 服务端给的 end_time)`。
   即"这句话的音频说完 → 文字定稿出现在我手里"的墙上时间。包含服务端识别与网络传输。
   必须按连接分别锚定：服务端时间戳每个 WebSocket 连接从 0 重新计数。
2. **首字延迟（firstTokenLatencyMs）**：该句第一个 partial 到达时刻 − (连接首包时钟 + 该句 start_time)。
   即"这句话开始说 → 屏幕先出字"的延迟，用户实际感知到的响应速度。
