# 演示脚本（3–5 分钟）

> 本脚本按《AI盯播工具七天开发方案.md》第 17 节整理。总时长约 4 分钟（240 秒），可裁剪到 3 分钟。
>
> **演示配置（必须标明，与产品默认不同）：**
> - 分析间隔 **30 秒**、分析窗口 **3 分钟**
> - 产品默认为 **每 60 秒分析最近 5 分钟**
> - 画面或口播必须显示/说明：「当前为演示配置：每 30 秒分析最近 3 分钟；产品默认每 60 秒分析最近 5 分钟」
>
> **真实性标注要求：**
> - 用真实音频（直播回放 / 现场讲解）演示时，视频开头或口播必须说「真实音频，现场 ASR 与 AI 分析」。
> - 用 fixture 数据讲解时，必须全程标注「模拟数据」，严禁说成「真实 ASR / LLM 已验收」。

## 0. 演示前准备（不进 4 分钟计时）

1. 「分析设置」页配置好腾讯云 ASR（App ID / Secret ID / Secret Key）与 LLM（Base URL / 模型 / API Key），各点一次「测试连接」确认通过。
2. 把分析间隔改为 **30 秒**、窗口改为 **3 分钟**（保存后下一次会话生效）。
3. 导入话术框架：`fixtures/framework-sample.json`（演示数据，标注模拟）。
4. 准备真实音频源（二选一）：
   - 浏览器播放一段直播回放，用「监听系统声音」共享该标签页并**勾选分享音频**；
   - 或直接用麦克风现场讲解。
5. 关掉其他可能发声的程序，戴耳机避免回授。
6. 预演一遍，确认问题卡片能在 90 秒内出现。

## 1. 启动与连接状态（约 20 秒）

- 启动「AI盯播工具」，指出右上角「MVP · 本地运行 · 数据不出本机」。
- 切「分析设置」页：ASR / LLM 显示已配置（只显示脱敏尾号），强调密钥不明文展示。
- 切回「实时监控」页，说明即将监听的音源。
- **口播演示配置**：「现在是演示配置，每 30 秒分析最近 3 分钟，默认是每 60 秒分析最近 5 分钟。」

## 2. 导入话术框架（约 30 秒）

- 切「话术配置」页，点「导入 JSON」选 `fixtures/framework-sample.json`（标注：模拟数据）。
- 指着三类内容的区分讲：
  - 「已核实商品事实」——允许作为 AI 判断输入；
  - 「建议话术 / 热词」——只作参考与提示；
  - 「风险表达规则」——只触发提示，不直接判定违法。
- 点「保存（Zod 校验）」，说明前后端双重校验。

## 3. 开始监听真实音频（约 40 秒）

- 切「实时监控」页，选音源，点「开始监听」（麦克风或系统声音）。
- 用真实直播回放播放，或现场念一段含风险表达的话，例如：
  「这款保温杯百分之百二十四小时保温，所有人用了都说好，赶紧下单拍一号链接！」
- 指着顶部状态区讲：采集「采集中」、ASR「识别中」、音频电平跳动、最后稳态时间在刷新。

## 4. 展示实时转写（约 30 秒）

- 指着字幕区两条流：
  - 灰色斜体「临时」字幕——识别中间结果，会变，不落库；
  - 黑色「稳态」字幕——定稿内容，带相对时间与片段号。
- 补一句：「ASR 断线时会显示转写缺口提示，不会拿旧文本冒充新文本。」

## 5. 等待分析结果（约 40 秒）

- 说明：开始监听后已讲了约 1 分钟，窗口里已积累内容；**第一轮（0–30 秒）分析内容少、问题稀疏属正常**。
- 分析触发时顶部状态短暂显示「分析中」，此时字幕不中断——强调「分析期间 ASR 不停止」。
- 问题卡片出现后逐个讲：
  - 「绝对化用语」类来自规则引擎，秒级；
  - LLM 分析的问题稍晚到——原话证据高亮、判断依据、改进建议、参考话术；
  - 「需人工核查」徽标：LLM 不确定的输出不会被当成确认问题。

## 6. 展示原话证据与溯源（约 30 秒）

- 点问题卡片「定位原句」——字幕区对应稳态片段高亮 1.5 秒。
- 指着卡片上的 `segment_id` 和时间戳：每个问题都能溯源到具体转写片段。
- 补一句：LLM 引用的原话必须是指向片段原文的连续子串，伪造引用在校验阶段就被拒绝。

## 7. 历史与报告（约 30 秒）

- 点「结束」停止监听，切「历史与报告」页。
- 会话列表显示刚才的会话：稳态条数、问题数。
- 打开报告视图：会话信息、ASR/LLM 请求与失败统计、数据缺口提示、问题时间轴、话术指标（语速双口径 / 讲话 / 静音）。

## 8. 导出报告（约 20 秒）

- 点「导出 HTML 报告」，选择保存位置，打开文件。
- 指出：完整报告可离线查看，**导出不含任何 API Key 或服务配置**。

## 收尾话术（约 15 秒）

- 一句总结：规则引擎兜底秒级提醒，LLM 提供深度建议，所有问题可溯源、可导出，数据不出本机。
- 诚实声明：已知限制见 README「已知限制」与交付文档，未实测项均已标注。

## 无密钥的替代演示（Plan B）

如果演示环境无法配置真实 ASR / LLM：

1. 全程标注「模拟数据演示」，明确说明这不是真实识别。
2. 用 fixture 的 ASR 消息（`fixtures/asr-partial-final.json`、`fixtures/asr-reconnect.json`）讲解临时 / 稳态分离与断线去重逻辑（可展示单测输出）。
3. 用 `fixtures/llm-valid.json`、`fixtures/llm-fake-evidence.json` 讲解 LLM 输出校验：伪造 segmentId、伪造引文如何被拒绝。
4. 用「分析设置」→ 导出 JSON 报告展示历史会话数据结构。
5. **严禁把 fixture 演示说成「真实 ASR / LLM 已验收」。**
